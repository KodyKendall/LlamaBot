# 0.7.20.2 test plan

## LP-50: the builder over MCP (`/mcp`)

Automated: `app/tests/test_mcp_builder_server.py` (auth, every tool, queueing, cancel,
approvals, the off switch, size caps — fake agent, no database). Contract:
`docs/dev/builder_mcp_server.md`. The steps below need a real box and a real model.

Mint a token on the box (stays on the box):

```bash
docker exec leonardo-llamabot-1 python -c "import base64,hmac,hashlib,json,os,time;p=base64.urlsafe_b64encode(json.dumps({'username':'<box user>','exp':int(time.time())+600,'aud':'llamabot_mcp'}).encode()).rstrip(b'=').decode();s=base64.urlsafe_b64encode(hmac.new(os.environ['LLAMAPRESS_AI_LOGIN_SECRET'].encode(),p.encode(),hashlib.sha256).digest()).rstrip(b'=').decode();print(p+'.'+s)"
```
