## Sign in with Google / Microsoft

What the tests can't reach: a real Google / Microsoft login. You need your own OAuth app.

Setup (Google): Google Cloud console → APIs & Services → Credentials → OAuth client ID
(Web application). Authorized redirect URI:
`https://rails-<box>.llamapress.ai/users/auth/google_oauth2/callback`.

Setup (Microsoft): Entra admin center → App registrations → New registration, "Accounts in
any organizational directory and personal Microsoft accounts". Web redirect URI:
`https://rails-<box>.llamapress.ai/users/auth/entra_id/callback`. Then Certificates & secrets → new client secret.

Add to the box's `.env`, then `docker compose up -d --force-recreate llamapress`:

```
SSO_GOOGLE_CLIENT_ID=...
SSO_GOOGLE_CLIENT_SECRET=...
SSO_MICROSOFT_CLIENT_ID=...
SSO_MICROSOFT_CLIENT_SECRET=...
# optional: lock Microsoft to one company
# SSO_MICROSOFT_TENANT_ID=contoso.onmicrosoft.com
```

- [ ] Before adding the env vars: `/users/sign_in` looks exactly like 0.7.11 (no new buttons).
- [ ] After: "Continue with Google" and "Continue with Microsoft" appear above the email form, on desktop and phone width.
- [ ] Google, new email: you land on the app signed in; a user with that email now exists.
- [ ] Google, email of an existing password account: you land signed in as that same account (no duplicate user).
- [ ] Microsoft, new email: you land signed in as a new user.
- [ ] Microsoft, email of an existing password account: you are sent back to sign-in with "An account with that email already exists. Sign in with your password." (deliberate — Microsoft emails aren't verified).
- [ ] Sign out, sign in with the same Google account again: same user, no new row.
- [ ] Cancel on the Google screen: back on sign-in with "Couldn't sign you in with Google. Please try again." — not an error page.
- [ ] Inside the Leo chat preview, click "Continue with Google": the whole tab goes to Google (it can't load in the iframe) and comes back to the app signed in.
- [ ] Remove the env vars + recreate: buttons are gone, password sign-in still works.
