## Iframe session restore (remember the last previewed page + tab)

A full browser refresh of the chat page used to snap the preview back to the app root and
the "Your App" tab. It now reopens whatever page and tab you were last on.

**Setup**

- Box: https://llamapress-dev.llamapress.ai (or any box on this build).
- Frontend files are bind-mounted and served no-cache, so **no rebuild is needed** —
  just hard-refresh once (Cmd/Ctrl+Shift+R) before you start.
- Code: `app/frontend/chat/ui/IframeManager.js`. Automated coverage:
  `app/tests/js/iframe_session_restore.test.mjs`.

### Core behavior

- [ ] Load the chat page fresh. The preview opens on the app root (`/`) and the URL bar reads `/`.
- [ ] Click into a deeper page in the preview (e.g. a record), or type `/users` in the URL
      bar and hit Enter. Confirm the URL bar updates.
- [ ] Refresh the whole browser page (F5). **The preview comes back on that same page**, and
      the URL bar shows it immediately — it should not flash `/` first.
- [ ] Navigate back to the app root, refresh again. It stays on the root — the old deep link
      didn't stick.

### Tabs

- [ ] Switch to the **Feedback** tab, refresh the page. It reopens on Feedback.
- [ ] Switch back to **Your App**, refresh. It reopens on Your App.

### Close and reopen

- [ ] Navigate to a deep page, close the browser tab entirely, then reopen the chat URL.
      It still restores. (This is `localStorage`, not session-only — surviving a close is
      the intended behavior.)

### Doesn't leak across boxes

- [ ] Open a *different* LlamaPress box in the same browser. Its preview opens on its own
      root, unaffected by the first box's saved page.

### Doesn't break login

- [ ] Log out and log back in through the normal flow. The preview loads without a Rails
      login wall, and lands on your last page rather than the root.

### Role check — needs a `user`-role account

- [ ] As an engineer, switch to the **Code** tab. Then sign in as a `user`-role account
      (separate browser profile). It must open on **Your App** — never on a hidden Code or
      Tickets tab, which would strand them with no visible tab to click back to.

### Degrades safely

- [ ] Open the chat in a private/incognito window with cookies-and-site-data blocked. The
      preview still loads normally; it just won't remember anything.
