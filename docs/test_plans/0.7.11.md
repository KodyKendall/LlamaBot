hand-check what a test cannot reach.

## ZDR mode

Setup: a box the mothership has flagged ZDR (mbc-preceptors or leo-fenen after the
0.7.11 rollout). Wait one lease tick after the flag is set.

- [ ] The llamabot log shows `ZDR enforced: allowed_models=['deepseek-v4.1-flash-fireworks'] sensitivity=ferpa`.
- [ ] `bin/local/leo-zdr-check.sh` on the mothership shows the box's own `zdr` report with `enforced: true`, `tracing: off`, `web_search: off`.
- [ ] Every model except DeepSeek V4.1 Flash (Fireworks) is greyed out in the dropdown, **including ChatGPT Luna and Sol**.
- [ ] Send a message. It answers. A new thread's title is the start of your first message (no AI-written title).
- [ ] Ask Leo to "search the web for X". It says web search is disabled on this workspace; the turn does not error.
- [ ] Browser devtools → Network on the chat page: no requests to PostHog.
- [ ] Negative: remove the ZDR flag on the mothership. After one lease tick the log shows `ZDR off` and the dropdown returns to normal.

## ChatGPT picker on a normal box (no regression)

Setup: any non-ZDR box, ChatGPT not connected (a Base-plan box is ideal).

- [ ] ChatGPT Luna shows "(Connect account)" and is still selectable.
- [ ] Picking it opens the connect modal.

## Delete from My Uploads

Setup: any box, upload two files via paperclip → Upload to Assets (one image, one CSV).

- [ ] Paperclip → My Uploads → click a file. A red-on-hover **Delete** button sits next to Download.
- [ ] Click Delete → Cancel. Nothing changes.
- [ ] Click Delete → OK. The file leaves the list, the count drops, the preview resets to "Select an asset to preview".
- [ ] Close and reopen the modal (or hit refresh). The file is still gone.
- [ ] Attach the other file to the message, then delete it from the modal. Its chip disappears from the composer.

## Out of messages → keep going on your own ChatGPT

Setup: a box with `PAYWALL_ENABLED=true`, a user who is blocked (spend or message cap),
ChatGPT connected in the model picker.

- [ ] Send on DeepSeek/Muse. The "out of messages" card appears with a **Use your ChatGPT account** button above Upgrade. The card still names no limit, number or plan.
- [ ] Click it. The picker switches to Luna (my ChatGPT plan) and your last message is re-sent. Leo answers.
- [ ] Send another message on Luna. It goes straight through, no card, no page reload.
- [ ] Switch back to DeepSeek and send. The card appears again.
- [ ] Disconnect ChatGPT, click the card's button. The connect modal opens.
- [ ] Negative: admin-disable both ChatGPT models. The card shows no ChatGPT button.
